# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/Mrucznik/wonsz/security/advisories/new).
Do not open a public issue for security problems.

This is a hobby project maintained on a best-effort basis — reports are
appreciated, but there is no guaranteed response time.
